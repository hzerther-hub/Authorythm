# Yihao Shorts · PySide6-Ausgabe

> Eine All-in-One-KI-Werkstatt für Kurzfilme, Romane und Comics — 100 % funktionsgleich zur Open-Source-Web-Version, jetzt mit neuronaler Vorlesefunktion in 16 Sprachen.

> 黑盒分析: [docs/易好短剧-工具分析.md](docs/易好短剧-工具分析.md) · 实施计划: [PLAN.md](PLAN.md) · 过程记录: [PROGRESS.md](PROGRESS.md)
> 上游项目: [ooooinfo/yihao_drama](https://gitee.com/ooooinfo/yihao_drama.git) (Web 版) · 集成组件: [golanse/easymerger](https://github.com/golanse/easymerger) · [liangdabiao/video-clone-lite](https://github.com/liangdabiao/video-clone-lite)

## ✨ Kernfunktionen

🎬 **5 kreative Ziele**: Roman · Kurzfilm · Comic · Promotion (6 Plattformen × 6 Formate) · Viralvideo-Klon
🔧 **Sechsstufige Pipeline**: Rohtext → KI-Umschreibung → Visual Story → Storyboard → Comic → Zusammenfügen & Exportieren
🤖 **10 KI-Agenten**: Skript-Umschreibung, Charakter-/Szenen-Extraktion, Shot-Aufteilung, Prompts, Roman-Schreiben, Planung, 6-dimensionale Prüfung, Bearbeitung, Comic-Aufteilung, Promo-Text — System Prompts vollständig editierbar
🎙️ **Kostenlose Edge-TTS-Vorlese**: 16 Sprachen × 2 Geschlechter = 32 Microsoft-Neuronalstimmen, kein API-Schlüssel, keine Sprachpakete, nur Internet nötig. Projektweite Stimmen-Einstellung für konsistentes Kapitel
🎨 **Panelübergreifende Konsistenz**: Comic-Stapelgenerierung nutzt verkettete Keyframe-Übergabe (jedes fertige Panel-Bild füttert das nächste) plus `character_variants`-Mehrwinkel-Referenzen, Charaktere und Szenen bleiben panelübergreifend stabil

## 🚀 Schnellstart

- **Anforderungen**: Python 3.10+ (entwickelt mit 3.13)
- **Starten**: `py -3.13 -m app.main` oder `start.bat` doppelklicken
- **Vollständige Dokumentation**: siehe [Haupt-README](README.md)
