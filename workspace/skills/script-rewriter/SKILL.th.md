# คู่มือการปรับบท

## หลักการปรับ

1. **คงแก่นเรื่องหลักไว้**: ไม่เปลี่ยนเส้นเรื่องหลักและความสัมพันธ์ของตัวละคร
2. **เสริมความเห็นภาพ**: เปลี่ยนข้อความบรรยายเชิงเล่าเรื่องให้เป็นคำบรรยายฉากที่มองเห็นได้
3. **ขับเคลื่อนด้วยบทสนทนา**: ใช้บทพูดขับเคลื่อนเนื้อเรื่อง ลดบทบรรยาย
4. **ควบคุมจังหวะ**: ฉากหนึ่งฉากคุมความยาวที่ 30-60 วินาที เหมาะกับวิดีโอสั้น
5. **ไม่เขียนภาษากล้อง**: ไม่แตะเรื่องขนาดภาพ มุมกล้อง การเคลื่อนกล้อง สิ่งเหล่านี้เป็นขั้นตอนแยกสตอรีบอร์ด

## รูปแบบบทมาตรฐาน

```
## S01 | INT · ร้านกาแฟ | พลบค่ำ

แสงพลบค่ำไหลผ่านหน้าต่างเปลืองพื้นถึงเพดานลงสู่ร้านกาแฟ ไอระเหยจากแก้วกาแฟบนเคาน์เตอร์ลอยขึ้นพร่าน้ำตา

สมชายนั่งโดดเดี่ยวมุมบูธ ก้มมองโทรศัพท์ ท่าทางออกจะวิตกกังวล

เสียงกระดิ่งประตูดังขึ้น มาลีผลักประตูเดินเข้ามา เธอเห็นสมชาย จึงยิ้มและเดินไปหา

มาลี: (ยิ้ม) รอนานมากหรือเปล่า?
สมชาย: (เงยหน้า) ไม่นานหรอก เพิ่งมาถึง
```

### กฎรูปแบบ

- `## S<เลขที่> | INT/EXT · สถานที่ | ช่วงเวลา` — หัวฉาก
- คำบรรยายการกระทำเป็นย่อหน้าธรรมชาติ — ไม่มีภาษากล้องปนเลย
- `ชื่อตัวละคร: (สถานะ/สีหน้า) เนื้อหาบทพูด` — รูปแบบบทสนทนา

### อ้างอิงปริมาณเนื้อหา

บทมาตรฐานยาวกว่าเนื้อหาต้นฉบับประมาณ 20-30% ส่วนที่เพิ่มมาหลัก ๆ คือเครื่องหมายหัวฉากและการจัดรูปแบบบทสนทนา ไม่ใช่การขยายความ

## ขั้นตอนการปรับ

1. เรียก `read_episode_script` อ่านเนื้อหาต้นฉบับก่อน
2. วิเคราะห์โครงสร้างเนื้อหา (สัดส่วนบทสนทนา การบรรยาย คำบรรยายจิตใจ)
3. เรียก `rewrite_to_screenplay` ปฏิบัติการปรับบท
4. ตรวจสอบผลการปรับ ยืนยันว่าตรงตามรูปแบบบทมาตรฐาน
5. เรียก `save_script` บันทึกผลลัพธ์สุดท้าย

## ข้อควรระวัง

- คำบรรยายจิตใจต้องแปลงเป็นสีหน้า/การกระทำ/การตัดสินใจของตัวละคร หรือเป็นคำพูดที่พูดออกมาจริง — **ห้ามเสียงพากย์/คำบรรยาย/คำพูดในใจ**
- ทุกฉากต้องมีตัวละครอย่างน้อยสองคนโต้ตอบกันหน้ากล้อง ห้ามให้ตัวละครคนเดียวพูดกับห้องว่าง
- เปลี่ยนสถานที่หรือเวลาระหว่างฉากที่ต่อเนื่องกัน ห้ามใช้ห้องเดิมซ้ำติดต่อกัน
- ย่อหน้าบรรยายยาวแยกออกเป็นหลายฉากสั้น
- ยืนยันว่าทุกฉากมีจุดพลิกผันทางอารมณ์ที่ชัดเจน
- คงความสม่ำเสมอของสไตล์ภาษาของแต่ละตัวละคร
- เลขฉากไล่เพิ่มต่อเนื่องกัน (S01, S02, S03...)
- ช่วงเวลาต้องเจาะจง (พลบค่ำ ดึกดื่น รุ่งเช้า) ห้ามเขียนลอย ๆ ว่า "กลางวัน"
