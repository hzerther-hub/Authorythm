# พรอมต์สุดท้ายของตัวละคร (ด้านซ้าย: ภาพปิดใบหน้าตรง + ด้านขวา: ภาพสามมุมมอง)

สิ่งที่สร้างขึ้นคือ **แผ่นอ้างอิงตัวละคร (character turnaround sheet / character reference sheet, multi-view concept art layout)** ที่องค์ประกอบภาพถูกล็อกตายตัวเป็น:

- **ด้านซ้าย: ภาพปิดใบหน้าตรง** — ภาพระยะใกล้ด้านหน้าของศีรษะถึงไหล่ เห็นเค้าหน้า ทรงผม และผิวได้ชัดเจน ใช้เป็นจุดยึดความจำง่ายของใบหน้า
- **ด้านขวา: ภาพเต็มตัวสามภาพเรียงคู่กัน — หน้าตรง ด้านข้าง 90 องศา และด้านหลัง สูงเท่ากัน** — ภาพเต็มตัวสามมุมของตัวละครคนเดียวกันเรียงขนานกันในระดับความสูงเท่ากัน ขอบศีรษะด้านบนและฝ่าเท้าอยู่แนวเดียวกัน

**หลักการสำคัญ: ความสม่ำเสมอ > ความสวยงาม** ภาพนี้คือจุดยึดลุคของภาพตัวละครทุกภาพและการอ้างอิงวิดีโอทั้งหมดในเวลาต่อมา ต้องเป็นกลาง ชัดเจน และใช้ซ้ำได้ — ไม่ต้องไล่ตามความเป็นศิลปะของภาพเดี่ยว

## โครงสร้างผลลัพธ์ (ประกอบเป็นย่อหน้าเดียวต่อเนื่องตามลำดับนี้ ภาษาตามคำสั่งภาษาของเซสชัน)

```
character turnaround sheet, character reference sheet, multi-view concept art layout, orthographic views, no perspective distortion;
ด้านซ้ายเป็นภาพปิดใบหน้าตรง ด้านขวาเรียงภาพเต็มตัวสามภาพ หน้าตรง / ด้านข้าง 90 องศา / ด้านหลัง สูงเท่ากัน,
ภาพเต็มตัวทั้งสามแบบ evenly spaced panels ขอบศีรษะด้านบนกับฝ่าเท้าอยู่แนวเดียวกัน;
ภาพปิดและภาพเต็มตัวเป็นตัวละครคนเดียวกัน ตัวเต็มอยู่ในเฟรม A-pose ยืนท่าเป็นกลาง สีหน้าธรรมชาติไม่แสดงอารมณ์,
[ความรู้สึกอายุ + ความรู้สึกเพศ + รูปร่าง], [เค้าหน้า], [ทรงผม], [เสื้อผ้า + เครื่องประดับ],
ใบหน้า ทรงผม และเสื้อผ้าของภาพปิดหน้าตรงกับสามภาพมุมมองนั้นเหมือนกันทุกประการ,
พื้นหลังขาวล้วน แสงนุ่มสม่ำเสมอ โทนภาพยนตร์
```

## กฎลำดับการบรรยาย

วาง**คุณสมบัติที่จำง่ายที่สุดไว้ต้นสุด** เดินตามลำดับนี้เพื่อสร้างสมาชิกสำคัญทุกตัวของ `appearance` (ลักษณะภายนอก) และ `styling` (การจัดลุค) ให้ครบถ้วนไม่ตกหล่น:

1. จุดยึดตัวตน: ความรู้สึกอายุ (เช่น "ยี่สิบต้น ๆ") ความรู้สึกเพศ รูปร่าง (สูง-เตี้ย อ้วน-ผอม ท่าทางนิสัย)
2. เค้าหน้า: รูปหน้า ดวงตา คุณสมบัติเด่นอื่น ๆ (แผลเป็น ไฝ แว่นตา ฯลฯ) — ภาพปิดหน้าตรงพึ่งพาการบรรยายส่วนนี้เป็นพิเศษ
3. ทรงผม: สี ความยาว สไตล์
4. เสื้อผ้า: แบบ สี วัสดุ สภาพ (เช่น "ชุดยูดง่ายที่ข้อมือมีรอยด่างจากตะกั่วบัดกรี")
5. เครื่องประดับ: เขียนเฉพาะชิ้นที่จำง่าย ไม่รวบรวมกองรวมกัน

นิสัยของตัวละครต้องเปลี่ยนเป็นบรรยายบุคลิกภายนอกและสีหน้า (เช่น "อิดโรย" → "แววตาอ่อนล้า ไหล่ตกเล็กน้อย") ห้ามให้คำบอกนิสัยปรากฏโดยตรง

## องค์ประกอบภาพและความสม่ำเสมอ

- ภาพปิดหน้าตรงด้านซ้าย: หันหน้าตรงเข้าหากล้อง สีหน้าเป็นกลาง ศีรษะถึงไหล่อยู่ในเฟรมครบถ้วน
- ภาพเต็มตัวสามภาพด้านขวา: หน้าตรง ด้านข้าง 90 องศา และด้านหลังของตัวละครคนเดียวกัน **สูงเท่ากัน เรียงขนานกัน ระยะห่างสม่ำเสมอ** ขอบศีรษะด้านบนและฝ่าเท้าอยู่แนวนอนเดียวกัน
- ภาพปิดกับภาพเต็มตัวสามภาพต้องเป็นใบหน้าเดียวกัน ทรงผมเดียวกัน เสื้อผ้าเดียวกัน — บอกออกมาชัดเจนว่า "ใบหน้า ทรงผม และเสื้อผ้าของภาพปิดหน้าตรงกับสามภาพเต็มตัวนั้นเหมือนกันทุกประการ"
- ยืนท่าเป็นกลาง สีหน้าธรรมชาติ — ง่ายต่อการนำไปใช้ซ้ำเป็นภาพอ้างอิง
- มือเท้าปกติ: ในภาพเต็มตัว มือต้องมีนิ้วห้านิ้วปกติ เท้ามีนิ้วเท้าห้านิ้ว แขนสองขาสอง ไม่มีแขนขาส่วนเกิน; มือพักผ่อนตามธรรมชาติ ไม่ทำท่ามือซับซ้อน (ลดโอกาสวาดมือบิดเบี้ยว)
- **เพดานแข็งของจำนวนตัวละครที่ปรากฏทั้งหมด: ภาพปิดหน้าตรง 1 ภาพ + ภาพเต็มตัว 3 ภาพ = รวม 4 ตัวละคร ห้ามมีมากกว่านี้** (โปรดทราบ: ภาพเต็มตัว 3 ภาพนั้นโดยตัวมันเองคือตัวละครคนเดียวกันจากสามมุม — หน้าตรง / ด้านข้าง 90 องศา / ด้านหลัง นี่คือเจตนาการออกแบบ ไม่ใช่ "การทำสำเนา"; สิ่งที่ห้ามคือการวาดตัวละครคนเดิมออกมาอีกสำเนาหนึ่งเพิ่มเติม หรือการยัดตัวละครอยู่ในเฟรมเดียวกันเพิ่มนอกเหนือจาก 3 ภาพเต็มตัว; ภาพเต็มตัวทั้ง 3 ภาพต้องแสดงทิศทางที่ต่างกันชัดเจน ซ้าย / กลาง / ขวา คือหน้าตรง / ด้านข้าง 90 องศา / ด้านหลังตามลำดับ ห้ามเป็นหน้าตรงทั้งหมดเด็ดขาด)
- ตัวละครคนเดียว: ทั้งภาพมีได้เพียง 4 ตัวละครตามที่กล่าวข้างต้น ไม่มีเงาซ้อน ร่างแยก หรือสำเนาหลายคน; เค้าหน้าคงเส้นคงวา ไม่บิดเบี้ยว ไม่ละลาย
- แสงสตูดิโอนุ่มนวลสม่ำเสมอ ไม่ใช้แสงเงาอันเต็มไปด้วยการละคร (ภาพอ้างอิงต้องใช้ได้กับฉากทุกชนิด)
- ผลลัพธ์ใช้ภาษาเป้าหมายตามที่คำสั่งภาษาของเซสชันกำหนด ห้ามใส่คำศัพท์ที่ไม่เกี่ยวข้องปนเข้าไป

## สิ่งที่ห้าม

- ท่าทางเคลื่อนไหว สีหน้าเกินจริง ถือไอเทม อยู่ในเฟรมเดียวกับคนอื่น
- **ตัวละครเกิน 4 ตัว (ภาพปิด 1 + ภาพเต็มตัว 3); ภาพเต็มตัวทั้ง 3 คือตัวละครคนเดียวกันจากสามมุม (หน้าตรง / ด้านข้าง 90 องศา / ด้านหลัง) — นั่นคือเจตนาการออกแบบ ไม่ใช่ข้อห้าม; สิ่งที่ห้ามคือการสำเนาตัวละครเดียวกันเพิ่มนอกเหนือจากภาพเต็มตัว 3 ภาพ หรือการวาดภาพเต็มตัวทั้ง 3 เป็นหน้าตรงเหมือนกันหมด / กองรวมกันอยู่กลางภาพ / ทับซ้อนกัน / สูงไม่เท่ากัน**
- ตัดร่างกายออก (ภาพเต็มตัวต้องเป็น full body ศีรษะถึงฝ่าเท้าอยู่ในเฟรมครบ; ภาพปิดต้องเห็นศีรษะและไหล่ครบถ้วน)
- นิ้วมือหกนิ้ว นิ้วติดกัน นิ้วขาด ความผิดปกติแบบหลอมรวม; มือสามมือ ขาสามขา แขนขาส่วนเกิน ความบิดเบี้ยวจากการสำเนา
- เงาซ้อน ร่างแยก สำเนาหลายคน; เค้าหน้าบิดเบี้ยว ใบหน้าละลาย
- ข้อความ ฉลาก ลายน้ำ ลายเซ็น; โลโก้แบรนด์จริง หน้าดาราจริง
- เงาทึบหนา แสงพื้นหลังสี ไอเทมในพื้นหลัง
