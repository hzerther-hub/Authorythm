# 캐릭터 최종 프롬프트(좌측 정면 얼굴 클로즈업 + 우측 삼면도)

생성물은 캐릭터 설정 참조 이미지(character reference sheet)이며, 구도는 다음과 같이 고정됩니다:

- **좌측: 정면 얼굴 클로즈업** — 머리와 어깨의 정면 근경. 이목구비, 헤어스타일, 피부 질감이 선명하게 보이며, 얼굴 식별도의 앵커 역할을 합니다
- **우측: 정면, 90도 측면, 후면의 같은 키 전신 뷰 3장을 나란히 배치** — 같은 캐릭터의 세 가지 전신 뷰를 같은 키로 나란히 놓고, 머리 꼭대기와 발바닥을 정렬합니다

**핵심 원칙: 일관성 > 아름다움.** 이 이미지는 이후 모든 캐릭터 이미지·비디오 참조의 이미지 앵커이므로, 중립적이고 선명하며 재사용 가능해야 합니다 — 단일 이미지의 예술성을 추구하지 마세요.

## 출력 구조(이 순서대로 하나의 연결된 문장으로 조립, 언어는 세션 언어 지시를 따름)

```
character turnaround sheet, character reference sheet, multi-view concept art layout, orthographic views, no perspective distortion.
좌측은 정면 얼굴 클로즈업, 우측은 정면, 90도 측면, 후면의 같은 키 전신 뷰 3장을 나란히 배치.
세 가지 전신 뷰는 evenly spaced panels, 머리 꼭대기와 발바닥이 정렬됨.
클로즈업과 전신 뷰는 모두 같은 캐릭터이며, 전신이 화면에 들어오고, A-pose 중립적인 서기 자세, 자연스러운 표정.
[나이대 + 성별감 + 체형], [이목구비 특징], [헤어스타일], [의상 + 액세서리].
정면 얼굴 클로즈업과 세 가지 뷰의 얼굴, 헤어스타일, 의상이 완전히 동일.
순백 배경, 부드럽고 고른 조명, 영화적 질감
```

## 묘사 순서 규칙

**가장 식별도가 높은 특징을 앞에 배치**하고, 이 순서대로 `appearance`(외모)와 `styling`(스타일링)의 모든 핵심 요소를 누락 없이 구체화합니다:

1. 정체성 앵커: 나이대(예: "스물 초반"), 성별감, 체형(키와 몸매, 자세 습관)
2. 이목구비: 얼굴형, 눈, 기타 뚜렷한 특징(흉터, 점, 안경 등) — 정면 얼굴 클로즈업이 특히 이 부분 묘사에 의존합니다
3. 헤어스타일: 색상, 길이, 스타일
4. 의상: 디자인, 색상, 소재, 상태(예: "소매에 납땜 자국이 있는 구겨진 작업복")
5. 액세서리: 식별도가 있는 것만 쓰고, 잔뜩 쌓지 마세요

캐릭터의 성격 특징은 외적인 분위기와 표정 묘사로 전환합니다(예: "초췌함" → "피로한 눈빛, 살짝 처진 어깨"). 성격 단어를 직접 쓰지 마세요.

## 구도와 일관성

- 좌측 정면 얼굴 클로즈업: 카메라를 정면으로 향하고, 중립적인 표정, 머리 꼭대기부터 어깨까지 완전히 화면에 들어옴
- 우측 세 가지 전신 뷰: 같은 캐릭터의 정면, 90도 측면, 후면. **같은 키로 나란히, 간격 균일**, 머리 꼭대기와 발바닥이 같은 수평선 위에 있음
- 클로즈업과 세 가지 전신 뷰는 반드시 같은 얼굴, 같은 헤어스타일, 같은 의상이어야 합니다 — "정면 얼굴 클로즈업과 세 가지 전신 뷰의 얼굴, 헤어스타일, 의상이 완전히 동일"하다고 명시적으로 쓰세요
- 중립적인 서기 자세, 자연스러운 표정 — 참조 이미지로 재사용하기 좋게 합니다
- 부드럽고 고른 스튜디오 조명, 극적인 명암 금지(참조 이미지는 어떤 장면에서도 쓸 수 있어야 함)
- **캐릭터 인스턴스 총수의 하드 캡: 정면 얼굴 클로즈업 1개 + 전신 뷰 3개 = 총 4개. 그 이상 등장시키지 마세요** (참고: 세 전신 뷰는 본래 '같은 캐릭터의 정면 / 90도 측면 / 후면'이라는 설계 의도이며 '복제'가 아님. 금지되는 것은: 세 전신 뷰 밖에 같은 캐릭터를 한 번 더 추가하는 것, 세 전신 뷰를 모두 같은 정면 자세로 그리는 것, 화면 중앙에 쌓거나 / 겹치거나 / 높이를 어긋나게 배치하는 등 불균등한 배치를 하는 것)
- 출력은 세션 언어 지시가 지정한 목표 언어를 사용하고, 무관한 어휘를 섞지 마세요

## 금지 사항

- 역동적인 포즈, 과장된 표정, 소품을 손에 든 모습, 다른 사람과 함께 등장
- **캐릭터 인스턴스가 4개를 초과하는 것(클로즈업 1 + 전신 뷰 3). 세 전신 뷰는 같은 캐릭터의 정면 / 90도 측면 / 후면이라는 설계 의도이며 금지해야 할 '복제'가 아닙니다. 금지되는 것은: 세 전신 뷰 밖에 같은 캐릭터를 추가로 한 번 더 그리는 것, 세 전신 뷰를 모두 정면 자세로 그리는 것, 화면 중앙에 쌓거나 / 겹치거나 / 높이를 어긋나게 배치하는 등 불균등 배치를 하는 것**
- 신체 잘림(전신 뷰는 반드시 full body로 머리 꼭대기부터 발바닥까지 완전히 화면에 들어와야 함; 클로즈업은 머리와 어깨가 완전히 들어와야 함)
- 텍스트, 라벨, 워터마크, 서명
- 짙은 그림자, 컬러 배경광, 배경 소품
