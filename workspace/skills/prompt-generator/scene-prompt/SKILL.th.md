# พรอมต์สุดท้ายของฉาก (ช็อตสถาปนามุมกว้าง · ช็อตเปล่าไม่มีคน)

สิ่งที่สร้างขึ้นคือภาพฉาก **ช็อตสถาปนามุมกว้าง (establishing shot) ที่ชัดเจน**: ช็อตเปล่าล้วน ๆ ของฉากที่**ไม่มีคนอยู่เด็ดขาด** แสดง**ตำแหน่งสัมพัทธ์ที่คงที่ของฉากหน้า ฉากกลาง ฉากหลัง ทางเข้า-ออก พื้น ผนัง และเครื่องประกอบฉากหลัก**ได้อย่างสมบูรณ์ โครงสร้างพื้นที่ต่อเนื่อง สอดคล้องกันเอง และใช้ซ้ำได้

ภาพนี้จะเป็นจุดยึดอ้างอิงพื้นหลังของทุกช็อตในฉากนี้: ผู้ชมและโมเดลต่างต้องอ่านโครงผังพื้นที่ทั้งหมดได้จากภาพนี้ — เข้า-ออกจากทางไหน พื้นและผนังมีพื้นผิวแบบไหน เครื่องประกอบฉากหลักแต่ละชิ้นหยั่งรากอยู่ตรงไหน มุมกล้องต้องมั่นคง เป็นสากลใช้ได้ทั่วไป

## โครงสร้างผลลัพธ์ (ประกอบเป็นย่อหน้าเดียวต่อเนื่องตามลำดับนี้ ภาษาตามคำสั่งภาษาของเซสชัน)

```
กล้องมุมตายมุมกว้าง ช็อตสถาปนาที่ชัดเจน [สถานที่ + บรรยากาศยุคสมัย] [ช่วงเวลา],
องค์ประกอบภาพสามชั้น — ฉากหน้า ([องค์ประกอบฉากหน้า]) ฉากกลาง ([พื้นที่หลักของฉากกลาง]) ฉากหลัง ([ความลึกของฉากหลัง]),
ทางเข้า-ออก ([ตำแหน่งและแบบของประตู/ทางเดิน]) พื้น ([วัสดุพื้นและสภาพ]) ผนัง ([วัสดุผนังและสี]),
[เครื่องประกอบฉากหลักและตำแหน่งสัมพัทธ์ที่หยั่งรากของมัน],
โครงสร้างพื้นที่ต่อเนื่องและสอดคล้องกันเอง,
[แหล่งแสง + อุณหภูมิสี + ความเปรียบเทียบสว่าง-มืด] [อารมณ์บรรยากาศ],
ไม่มีตัวละครใด ๆ ในภาพ ฉากเปล่า โทนภาพยนตร์
```

## กฎโครงสร้างพื้นที่

พื้นที่ต้อง**อ่านเข้าใจได้ เข้ากันได้ ใช้ซ้ำได้**:

- **ฉากหน้า**: กรอบภาพ/สิ่งบังพื้นที่ (ขอบประตู มุมโต๊ะ ต้นไม้ ขอบเครื่องจักร) สร้างความลึก — เขียนให้มีองค์ประกอบเฉพาะ 1-2 ชิ้น
- **ฉากกลาง**: พื้นที่หลักของฉากและเครื่องประกอบฉากแกนกลาง (สายการผลิต เตียง เคาน์เตอร์)
- **ฉากหลัง**: การต่อขยายของพื้นที่ (ผนังไกล หน้าต่าง ทางเดิน เส้นขอบฟ้าเมือง)
- **ทางเข้า-ออก**: ตำแหน่งและแบบของประตู บันได ทางเดิน ต้องชัดเจนเด่นชัด (เช่น "ประตูเหล็กบานหนึ่งอยู่ฝั่งซ้ายของเฟรม") นี่คือรากฐานการจัดจรเข้า-ออกของตัวละครในช็อตเวลาต่อมา
- **พื้นและผนัง**: ทำให้วัสดุ สี สภาพเป็นรูปธรรม (เช่น "พื้นคอนกรีตมีคราบน้ำมัน" "ผนังปูนขาวลอกเป็นขุยกระจัดกระจาย")
- **เครื่องประกอบฉากหลัก**: เขียนให้มีเครื่องประกอบฉากแกนกลาง 2-4 ชิ้น และ**ตำแหน่งสัมพัทธ์ที่หยั่งราก**ของมัน (เช่น "สายการผลิตเรียงรายยาวไปตามผนัง สุดท้ายคือเคาน์เตอร์บาร์") ความสัมพันธ์ซ้าย-ขวา/ใกล้-ไกลระหว่างเครื่องประกอบฉากต้องสอดคล้องกันเอง ห้ามแค่เขียนรายชื่อสิ่งของเป็นลิสต์

## คน (กฎแข็ง · ลำดับความสำคัญสูงสุด)

**ในภาพฉากห้ามมีคนปรากฏขึ้นโดยเด็ดขาด ให้เหลือไว้เพียงฉากเท่านั้น**

- ในพรอมต์ไม่บรรยายคน ไม่เอ่ยถึงสิ่งใดที่เกี่ยวข้องกับคน
- ข้อมูลเกี่ยวกับคนที่ปรากฏในคำบรรยายฉาก (prompt) ให้ละเว้นทั้งหมด ไม่เขียนลงในพรอมต์
- ท้ายพรอมต์ต้องประกอบด้วย: "ไม่มีตัวละครใด ๆ ในภาพ ฉากเปล่า"

เครื่องประกอบฉาก บรรยากาศยุคสมัย และองค์ประกอบภาพสำคัญใน `prompt` (คำบรรยายฉาก) ต้องลงมือทำครบทั้งหมด; `lighting` (แสงเงาของฉาก) ต้องทำให้เป็นรูปธรรม: ทิศทางแหล่งแสง อุณหภูมิสีอุ่น-เย็น ความเปรียบเทียบสว่าง-มืด (เช่น "หลอดไฟเพดานเปล่งแสงขาวเย็น เงาแข็งตกลงใต้เครื่องจักร")

## มุมกล้องและอารมณ์บรรยากาศ

- มุมกว้างระดับสายตาที่มั่นคงหรือเงยลงเล็กน้อย ไม่ใช้มุมเงย-มองลงสุดขีด มุมปลา (fisheye) หรือองค์ประกอบภาพเอียง (จะต้องนำมาใช้ซ้ำเป็นฉากคงที่หลายครั้ง)
- ใช้ `location` + `time` กำหนดช่วงเวลาและโทนแสงหลัก (แสงกลางวัน/กลางคืน/พลบค่ำแตกต่างกันสิ้นเชิง)
- ทำให้คำอารมณ์บรรยากาศเป็นรูปธรรม: "อึดอัดขัดข้อง" → "อากาศอบอ้าว แสงมืดหม่นต่ำ" ห้ามเขียนแค่คำอารมณ์นามธรรม
- ผลลัพธ์ใช้ภาษาเป้าหมายตามที่คำสั่งภาษาของเซสชันกำหนด ห้ามใส่คำศัพท์ที่ไม่เกี่ยวข้องปนเข้าไป

## สิ่งที่ห้าม

- คนแม้แต่คนเดียว — **ในภาพฉากห้ามมีคนปรากฏขึ้นเด็ดขาด ให้เหลือไว้เพียงฉากเท่านั้น**
- ข้อความ ตัวหนังสืออ่านออกบนป้าย ลายน้ำ ลายเซ็น โลโก้แบรนด์จริง
- ความเบลอจากการเคลื่อนไหว วัตถุที่กำลังเคลื่อนที่ (ภาพอ้างอิงฉากต้องนิ่งและมั่นคง)
- เพียงลิสต์รายการเครื่องประกอบฉากโดยไม่บอกตำแหน่งสัมพัทธ์ (โครงสร้างพื้นที่ต้องต่อเนื่องและสอดคล้องกันเอง)
