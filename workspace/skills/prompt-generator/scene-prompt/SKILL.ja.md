# シーン最終プロンプト（広角エスタブリッシングショット · 人物なしの空カット）

生成するのは**明瞭な広角エスタブリッシングショット（establishing shot）**のシーン画像：**完全に人物のいない**純粋なシーンの空カットで、**前景、中景、後景、出入口、床、壁、および主要な調度品の固定的な相対位置**を完全に示し、空間構造が連続し、自己完結的で、再利用可能でなければならない。

この画像はそのシーンのすべてのカットの背景参照アンカーとなる：観客もモデルもこの1枚から空間全体のレイアウトを読み取れなければならない——どこから出入りするのか、床と壁はどんな質感か、中核となる調度品がそれぞれどの位置に固定されているか。視点は安定していて汎用的でなければならない。

## 出力構造（この順序で1段落の連続した記述を組み立てる。言語はセッションの言語指令に従う）

```
固定カメラの広角ショット、明瞭なエスタブリッシングショット。[場所 ＋ 年代の質感]、[時間帯]。
前景（[前景の要素]）、中景（[中景の主体空間]）、後景（[後景の奥行き]）の3層に分かれた構図。
出入口（[ドア／通路の位置と様式]）、床（[床の材質と状態]）、壁（[壁の材質と色]）。
[主要な調度品とその固定的な相対位置]。
空間構造は連続し、自己完結的。
[光源 ＋ 色温度 ＋ 明暗のコントラスト]、[雰囲気]。
シーンに人物はいません、空のシーン。映画の質感
```

## 空間構造のルール

空間は**読み取れ、対応が取れ、再利用可能**でなければならない：

- **前景**：フレーミング／遮蔽物（ドア枠、テーブルの角、植物、機器の縁）で奥行きを作る——具体的な要素を1〜2個書く
- **中景**：シーンの主体となる空間と中核の調度品（流れ作業のライン、ベッド、カウンター）
- **後景**：空間の広がり（遠くの壁、窓、廊下、街の輪郭）
- **出入口**：ドア、階段、通路の位置と様式を明確にする（例：「画面左側に鉄のドアが1枚」）。これは後続のカットで人物を出入りさせる演出の根拠となる
- **床と壁**：材質、色、状態を具体化する（例：「コンクリートの床に油の染み」「壁の漆喰が斑に剥がれている」）
- **主要な調度品**：中核となる調度品を2〜4個書き、それらの**固定的な相対位置**を示す（例：「流れ作業のラインが壁沿いに並び、その突き当たりにカウンター」）。調度品同士の左右／遠近の関係は自己完結的であること。物品名を単に列挙しない

## 人物（硬性ルール · 最優先）

**シーン画像にはいかなる人物も出してはならず、シーンそのものだけを残す。**

- プロンプトに人物を描写せず、人物に関連するいかなる内容にも言及しない
- シーン描写（prompt）に登場する人物情報は一律に無視し、プロンプトに書き込まない
- プロンプトの末尾には必ず「シーンに人物はいません、空のシーン」を含める

`prompt`（シーン描写）中の調度品、年代の質感、重要な視覚要素はすべて漏れなく落とし込む；`lighting`（シーンの光影）は具体化する：光源の方向、色温度の寒暖、明暗のコントラスト（例：「頭上の蛍光灯が冷たい白光を放ち、機械の下に硬い影を落としている」）。

## 視点と雰囲気

- 安定した目線の高さかわずかな俯瞰の広角。極端な俯仰、魚眼、傾いた構図は使わない（固定シーンとして繰り返し再利用するため）
- `location` ＋ `time` で時間帯と光線の基調を定める（昼／夜／夕暮れでは光がまったく異なる）
- 雰囲気の語は具体化する：「息苦しい」→「空気が蒸し暑く、光線が暗く沈んでいる」。抽象的な感情語だけを書かない
- 出力はセッションの言語指令で指定されたターゲット言語を使い、無関係な語彙を混ぜない

## 禁止事項

- いかなる人物——**シーン画像にはいかなる人物も出してはならず、シーンそのものだけを残す**（後ろ姿、シルエット、反射・映り込み、写真の中の人物も含む）
- 文字、看板の読み取れる文字、透かし、署名
- モーションブラー、動いている物体（シーン参照画像は静止して安定している必要がある）
- 相対位置を示さず調度品のリストを羅列するだけ（空間構造は連続し、自己完結的でなければならない）
