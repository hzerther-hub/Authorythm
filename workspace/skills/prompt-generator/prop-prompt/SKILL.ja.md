# 小道具最終プロンプト（白背景単品 · 標準プロダクト撮影）

生成するのは白背景の単品画像（product shot）1枚：**標準的なプロダクト撮影の視点**を採用し、画面には小道具そのものだけがあり、純白の背景上に孤立して置かれ、**他のいかなる要素も混ぜない**——他の物品なし、人物なし、シーン環境なし、手で持つ描写なし。

3つの硬性要件：
1. **物品の各部の比率が正確**——誇張、変形、様式化された引き伸ばしをしない。小道具の相対的なサイズ関係は実際どおりでなければならない
2. **輪郭が完全**——小道具全体が完全に画面に収まり、四方に余白を残す。どの部分も画面の端で裁切してはならない
3. **背景はいかなる物語的内容も担わない**——純白の背景はあくまで下地であり、シーン感を帯びず、プロットの暗示を持たず、装飾要素を含まない

## 出力構造（この順序で1段落の連続した記述を組み立てる。言語はセッションの言語指令に従う）

```
単品プロダクト画像、標準的なプロダクト撮影の視点。[小道具名 ＋ 材質／色／形状／大きさ ＋ 新旧の度合いと摩耗の細部]。
物品の各部の比率は正確。純白の背景上に孤立して置かれ、中央に完全に収まり、輪郭は完全で裁切なし。
背景は無垢でいかなる物語的内容も担わない。他の物品なし、人物なし、シーンなし。
柔らかく均一なスタジオ光、淡い影、高精細
```

## 生成ルール

- 小道具の `name`（名称）と `description`（物品の外観）を中核とする：材質、色、形状、大きさ、新旧の度合い、摩耗の跡などの物理的な細部を**一項目ずつ漏れなく落とし込む**。これが小道具の識別性の源となる
- 標準的なプロダクト撮影の視点：わずかに俯瞰の3/4ビュー（上面と側面を同時に見せ、最も立体感がある）；平たい小道具（紙、証明書、写真）は真上からの俯瞰で平置きにする
- 単品を中央に完全に呈示し、四方に余白を残す。比率は正確、輪郭は完全。小道具の主体を裁切しない
- 柔らかく均一なスタジオ光、影は淡く、高精細
- 物品そのものだけを描写し、プロット、キャラクター、用途に言及しない（背景も画面も物語的内容を担わない）
- 出力はセッションの言語指令で指定されたターゲット言語を使い、無関係な語彙を混ぜない。**「映画の質感」類の語彙は使わない**（小道具画像は劇中スチルではなくプロダクト画像である）

## 禁止事項

- 手で持つ描写、人物、他の物品、シーン環境の写り込み
- 包装、台座、ディスプレイスタンド（それが小道具本体の一部である場合を除く）
- 文字、透かし、署名（小道具本体に印刷された文字や図柄は残し、描写してよい）
- 環境の反射、カラーの光
- 誇張されたパース、変形、比率の歪み、輪郭の裁切
