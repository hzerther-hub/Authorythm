# พรอมต์สุดท้ายของไอเทม (ชิ้นเดียวพื้นหลังขาวล้วน · การถ่ายสินค้ามาตรฐาน)

สิ่งที่สร้างขึ้นคือภาพสินค้าชิ้นเดียวพื้นหลังขาวล้วน (product shot): **ใช้มุมกล้องถ่ายสินค้ามาตรฐาน** ในเฟรมมีเพียงตัวไอเทมเท่านั้น วางอย่างโดดเดี่ยวบนพื้นหลังขาวสนิท **ไม่ปนเปื้อนองค์ประกอบอื่นใดเลย** — ไม่มีวัตถุอื่น ไม่มีคน ไม่มีสภาพแวดล้อมของฉาก ไม่มีมือถือชูขึ้นมา

ข้อกำหนดแข็งสามข้อ:
1. **สัดส่วนของทุกส่วนของวัตถุต้องแม่นยำ** — ห้ามเกินจริง บิดเบือน หรือยืดเส้นยืดสายแบบสไตล์ ความสัมพันธ์ของขนาดสัมพัทธ์ของไอเทมต้องเป็นจริง
2. **ขอบภาพครบถ้วน** — ตัวไอเทมทั้งชิ้นอยู่ในเฟรมครบถ้วน เว้นช่องว่างรอบด้าน ห้ามมีส่วนใดถูกขอบเฟรมตัดขาด
3. **พื้นหลังไม่รับบทบาทเนื้อหาใด ๆ ทางเรื่อง** — พื้นหลังขาวล้วนเป็นเพียงแผ่นรอง ไม่มีความรู้สึกเป็นฉาก ไม่มีใบ้เรื่องราว ไม่มีองค์ประกอบตกแต่ง

## โครงสร้างผลลัพธ์ (ประกอบเป็นย่อหน้าเดียวต่อเนื่องตามลำดับนี้ ภาษาตามคำสั่งภาษาของเซสชัน)

```
ภาพสินค้าชิ้นเดียว มุมกล้องถ่ายสินค้ามาตรฐาน [ชื่อไอเทม + วัสดุ/สี/รูปทรง/ขนาด + ความใหม่-เก่าและรายละเอียดร่องรอยการใช้งาน],
สัดส่วนของทุกส่วนของวัตถุแม่นยำ วางอย่างโดดเดี่ยวบนพื้นหลังขาวสนิท อยู่กึ่งกลางอยู่ในเฟรมครบถ้วน ขอบภาพครบไม่ถูกตัด,
พื้นหลังสะอาดไม่รับบทบาทเนื้อหาทางเรื่องใด ๆ ไม่มีวัตถุอื่น ไม่มีคน ไม่มีฉาก,
แสงสตูดิโอนุ่มนวลสม่ำเสมอ เงาบางเบา รายละเอียดสูง
```

## กฎการสร้าง

- ยึด `name` (ชื่อ) และ `description` (ลักษณะภายนอกของวัตถุ) ของไอเทมเป็นแกนหลัก: วัสดุ สี รูปทรง ขนาด ความใหม่-เก่า ร่องรอยการใช้งาน ฯลฯ รายละเอียดทางกายภาพเหล่านี้ต้อง**ลงมือทำครบทีละรายการ** นี่คือแหล่งกำเนิดความจำง่ายของไอเทม
- มุมกล้องถ่ายสินค้ามาตรฐาน: มุม 3/4 เงยลงเล็กน้อย (เห็นทั้งด้านบนและด้านข้าง เกิดมิติความลึกมากที่สุด); ไอเทมแบบแบน (กระดาษ บัตร ภาพถ่าย) ใช้การวางราบถ่ายจากบนลงตรง ๆ
- นำเสนอชิ้นเดียวกึ่งกลางอย่างครบถ้วน เว้นช่องว่างรอบด้าน สัดส่วนแม่นยำ ขอบภาพครบ ห้ามตัดตัวไอเทมหลักออก
- แสงสตูดิโอนุ่มนวลสม่ำเสมอ เงาบางเบา รายละเอียดสูง
- บรรยายเฉพาะตัววัตถุเท่านั้น ห้ามเอ่ยถึงเนื้อเรื่อง ตัวละคร หรือประโยชน์ใช้สอย (ทั้งพื้นหลังและเฟรมไม่รับบทบาทเนื้อหาทางเรื่อง)
- ผลลัพธ์ใช้ภาษาเป้าหมายตามที่คำสั่งภาษาของเซสชันกำหนด ห้ามใส่คำศัพท์ที่ไม่เกี่ยวข้องปนเข้าไป; **ห้าม**ใช้คำแนว "โทนภาพยนตร์" (ภาพไอเทมเป็นภาพสินค้า ไม่ใช่ภาพนิ่งจากหนัง)

## สิ่งที่ห้าม

- มือถือชูขึ้นมา คน วัตถุอื่น หรือสภาพแวดล้อมของฉากปรากฏในเฟรม
- บรรจุภัณฑ์ ฐานรอง แท่นวางจัดแสดง (เว้นแต่มันเป็นส่วนหนึ่งของตัวไอเทมเอง)
- ข้อความ ลายน้ำ ลายเซ็น โลโก้แบรนด์จริง (ข้อความและลวดลายที่พิมพ์อยู่บนตัวไอเทมเองสามารถคงไว้และบรรยายได้)
- แสงสะท้อนจากสภาพแวดล้อม แสงสี
- มุมมองเกินจริง ความบิดเบือน สัดส่วนผิดเพี้ยน ขอบภาพถูกตัด
