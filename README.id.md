# Yihao Shorts · Edisi PySide6

> Studio AI serba bisa untuk film pendek, novel, dan komik — 100% kesetiaan fitur dengan versi Web sumber terbuka, kini dengan pembacaan neural 16 bahasa.

> 黑盒分析: [docs/易好短剧-工具分析.md](docs/易好短剧-工具分析.md) · 实施计划: [PLAN.md](PLAN.md) · 过程记录: [PROGRESS.md](PROGRESS.md)
> 上游项目: [ooooinfo/yihao_drama](https://gitee.com/ooooinfo/yihao_drama.git) (Web 版) · 集成组件: [golanse/easymerger](https://github.com/golanse/easymerger) · [liangdabiao/video-clone-lite](https://github.com/liangdabiao/video-clone-lite)

## ✨ Fitur inti

🎬 **5 tujuan kreatif**: novel · film pendek · komik · promosi (6 platform × 6 format) · klon video viral
🔧 **Pipeline 6 tahap**: teks mentah → tulis ulang AI → cerita visual → storyboard → komik → gabung & ekspor
🤖 **10 agen AI**: tulis ulang skrip, ekstraksi karakter/latar, pemecahan shot, prompt, penulisan novel, perencanaan, tinjauan 6 dimensi, penyuntingan, pemecahan komik, teks promo — System Prompt dapat diedit sepenuhnya
🎙️ **Pembacaan Edge TTS gratis**: 16 bahasa × 2 gender = 32 suara neural Microsoft, tanpa API key, tanpa paket bahasa, cukup internet. Pengaturan suara tingkat proyek menjaga konsistensi bab
🎨 **Konsistensi antar panel**: pembuatan komik massal menggunakan umpan keyframe berantai (gambar panel yang selesai memberi makan panel berikutnya) + referensi multi-sudut `character_variants`, karakter dan latar tetap stabil antar panel

## 🚀 Mulai cepat

- **Persyaratan**: Python 3.10+ (dikembangkan diuji pada 3.13)
- **Jalankan**: `py -3.13 -m app.main` atau klik dua kali `start.bat`
- **Dokumentasi lengkap**: lihat [README utama](README.md)
