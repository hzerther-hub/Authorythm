# Yihao Shorts · Edición PySide6

> Estudio IA todo-en-uno para cortometrajes, novelas y cómics — 100% de paridad con la versión Web de código abierto, ahora con lectura en voz alta neuronal en 16 idiomas.

> 黑盒分析: [docs/易好短剧-工具分析.md](docs/易好短剧-工具分析.md) · 实施计划: [PLAN.md](PLAN.md) · 过程记录: [PROGRESS.md](PROGRESS.md)
> 上游项目: [ooooinfo/yihao_drama](https://gitee.com/ooooinfo/yihao_drama.git) (Web 版) · 集成组件: [golanse/easymerger](https://github.com/golanse/easymerger) · [liangdabiao/video-clone-lite](https://github.com/liangdabiao/video-clone-lite)

## ✨ Funciones principales

🎬 **5 objetivos creativos**: novela · cortometraje · cómic · promoción (6 plataformas × 6 formatos) · clonación viral
🔧 **Pipeline de 6 etapas**: texto crudo → reescritura IA → historia visual → storyboard → cómic → fusión y exportación
🤖 **10 agentes IA**: reescritura de guión, extracción de personajes/escenas, división de planos, prompts, escritura de novela, planificación, revisión 6 dimensiones, edición, división de cómic, texto promo — System Prompts totalmente editables
🎙️ **Lectura Edge TTS gratuita**: 16 idiomas × 2 géneros = 32 voces neuronales Microsoft, sin clave API, sin paquetes de idioma, solo internet. Ajuste de voz a nivel de proyecto para un capítulo coherente
🎨 **Coherencia entre viñetas**: la generación por lotes del cómic usa encadenamiento de keyframes (la imagen de cada viñeta alimenta la siguiente) + referencias multi-ángulo `character_variants`, personajes y escenas estables entre las viñetas

## 🚀 Inicio rápido

- **Requisitos**: Python 3.10+ (probado en 3.13)
- **Ejecutar**: `py -3.13 -m app.main` o doble clic en `start.bat`
- **Documentación completa**: consulta el [README principal](README.md)
