# 服务开通指南 —— 用好本软件需要开通哪些服务

本软件(易好短剧)本体**本地运行**(Windows 桌面端),项目的创建、
管理、剪辑、合并全部本地完成。但「AI 生成」能力(写剧本、出图、生视频、
配音、换脸)来自**外部 AI 服务**——你需要按自己要用的产线,去对应服务商
注册账号、充值并拿到 **API Key**,填进软件的「设置 → AI 服务」。

**不开通任何服务也能装、能开、能管理项目**;点生成按钮时会明确提示
「文本服务未就绪 / 配置缺少 API Key」,不会误发空请求。

---

## 一图看懂:按产线开通

| 你想干什么 | 必须开通 | 建议加开 | 说明 |
|---|---|---|---|
| 短剧(拆分剧本→分镜图→镜头视频→成片) | **文本** + **图像** | 视频、TTS | 全流程核心 |
| 小说(开书规划→逐章正文→审校) | **文本** | — | 规划/正文可分设两个模型 |
| 漫画(拆格→逐格出图→拼长图) | **文本** + **图像** | — | 跨格一致性依赖参考图能力 |
| 复刻带货视频(读原片→换产品重生成) | **文本(须多模态)** | 视频、图像 | 要看原片抽帧,模型必须支持读图 |
| 换脸 | **换脸服务**(本地或远程) | — | 见第五节 |
| 海外版(整书西化改写) | **文本** | — | — |
| 图库搜素材图(增强,不开也能用) | — | 图库 Key(三选一) | 任何一家挂了都不影响主流程 |

> 记忆口诀:**文本是发动机**(所有产线都要),图像/视频是腿,语音有免费路径。

## 二、七类服务总表

设置 → AI 服务 → 添加配置。每条配置 = 服务类型 + 服务商 + 模型 +
API Key(+ Base URL)。选服务商模板后 Base URL 与推荐模型会自动填好。

| 服务类型 | 用途 | 必须填 API Key? | 免费选项 |
|---|---|---|---|
| **text 文本** | 剧本/分镜/正文/审校/改写,一切「让 AI 写」 | ✅ 需要 | ❌ 无(本地大模型可走「自定义」) |
| **image 图像** | 角色立绘、三视图、首帧、分镜图、漫画格 | 云端 ✅ / 本地部署 ❌ | ComfyUI / SD WebUI / Fooocus(本机) |
| **video 视频** | 镜头视频、成片重制、带货复刻 | ✅ 需要 | ❌ 无(本地暂无模板) |
| **tts 语音** | 台词朗读、有声书 | 豆包要 Key | **微软 Edge(免费免Key)** / 本机语音(离线) |
| **faceswap 换脸** | 换脸工具页 | 本地 ❌ / 远程 ✅ | 本地 InsightFace 服务 |
| **jev 决策增强** | 视频 supplier 路由建议、诊断(可选) | ✅ 需要 | — 不开完全不影响使用 |
| **stockphoto 图库** | Unsplash/Pexels/Pixabay 搜图(可选) | ✅ 需要 | — 不开只是没有图库增强 |

## 三、文本服务(text)—— 必开

所有产线的「大脑」。内置模板(2026-11 版):

| 服务商模板 | Base URL | 推荐模型 | 备注 |
|---|---|---|---|
| DeepSeek 官方 | `https://api.deepseek.com/v1` | deepseek-v4-pro / flash | 结构化 JSON 规整,适合规划 |
| MiniMax 官方 | `https://api.minimaxi.com/v1` | MiniMax-M3 / M2.5 / M2 | 长文正文产量高(实测 6500 字/章无衰减) |
| Gemini 官方 | `https://generativelanguage.googleapis.com/v1beta/openai` | gemini-3.8-flash 等 | 支持读图(多模态) |
| OpenAI 官方 | `https://api.openai.com/v1` | gpt-5.6-terra 等 | — |
| Agnes 官方 | `https://apihub.agnes-ai.com` | agnes-3.0-flash 等 | 聚合平台,一把 Key 可同时配图像/视频 |
| 自定义… | 任意 OpenAI 兼容端点 | 自填 | 各类中转站/私有网关都走这里 |

要点:

- **小说线支持「规划模型 / 正文模型」分设**(设置里的两个下拉):
  推荐规划用 DeepSeek(结构规整)、正文用 MiniMax(字数足、不掉衰减)。
  不分设则统一用全局默认文本模型。
- **复刻带货线必须用多模态模型**(Gemini / Agnes 等能读图的):
  软件会把原片抽帧发给模型分析分镜,纯文本模型会凭空编造画面。
- 推理型模型(MiniMax-M3 / GLM)会先吐思维链再给 JSON,软件已内置
  解析兼容,无需特殊设置。

## 五、语音(tts)与换脸(faceswap)

### 语音 —— 有完全免费的路径

- **微软 Edge 语音(推荐起步)**:免费、免 Key、云端神经音色,
  中文默认晓晓/云希,自动按 gender 选声。
- **微软本机语音**:离线可用(Windows 自带语音),免 Key 免网络。
- **豆包语音(火山)**:`seed-tts-2.0`,效果最好,约 3 元/万字符,需 Key。
- 未配置语音时软件自动降级到 Edge;**显式选了 edge/local 的不降级**。

### 换脸 —— 两种都要额外跑一个服务

- **本地 InsightFace 换脸服务**:免费,需要你在本机(或局域网)启动
  InsightFace 服务端,默认地址 `http://127.0.0.1:5678`,无需 Key。
- **远程换脸 FaceMe**:`https://face.mei.biz`,付费,需 Key。

## 六、可选增强(不开完全不影响)

| 服务 | 作用 | 开通方式 |

## 七、本地组件(不是「服务」,无需开通)

- **ffmpeg**:视频转码/合并/抽帧,软件自动探测(可放 PATH 或 data 目录),
  缺了视频相关功能不可用。
- **ComfyUI / SD WebUI / Fooocus**:见上表,属「自己部署的免费图像服务」。

## 八、配置入口与安全

1. 顶栏「设置 → AI 服务 → 添加配置」:选服务类型 → 选服务商模板(自动填
   Base URL 和模型)→ 粘贴 API Key → 「测试配置」通过后保存。
2. 多条配置用「优先级 + 默认」排序;顶栏可随时切换当前使用的模型。
3. **API Key 的安全性**:Key 保存前自动用 Fernet 加密(密钥由本机指纹派生,
   不含用户名),明文只在本机内存中出现,`data/` 目录不进版本库。
   换电脑需重新输入 Key。
4. 配置里没有 Key 的免费服务(edge / local / comfyui / sdwebui /
   fooocus / local-faceswap)留空即可,软件不会强制要求。
