# 换脸服务 —— 安装与本地启动

本文讲两块东西:

1. **远程换脸**(provider = `remote-faceswap`):连别人的服务器,只填 Base URL + API Key
2. **本地换脸**(provider = `local-faceswap`):在自己机器上跑 InsightFace,填 `http://127.0.0.1:5678`

---

## 一、先判断你用哪种

「设置 → AI 服务 → 换脸」里,看 **服务商(provider)** 那一栏:

| provider | 含义 | Base URL 填什么 | 要不要自己装东西 |
|---|---|---|---|
| `remote-faceswap` | 用别人的服务器 | 对方给的地址,如 `https://face.mei.biz` | **不要** |
| `local-faceswap` | 自己机器上跑 | `http://127.0.0.1:5678` | **要**,见第二节 |

远程服务只要对方给了地址和 Key,填进去点「测试」能过就能用。剩下的报错
(`服务不可达(http://127.0.0.1:5678)`)说明**你其实配的是本地**,但服务没起。

---

## 二、本地换脸:安装与启动

### 2.1 它是什么

一个独立的 HTTP 服务,监听 `127.0.0.1:5678`,提供两个端点:

```
GET  /health   →  {"status": "ok", "model": "...", "providers": [...]}
POST /swap     →  {"ok": true, "image_base64": "..."}
```

本项目通过 `app/ai/face_swap.py` 调用它,和远程服务**协议完全一致** —— 所以
远程能跑通的机器,换成自建服务不用改任何代码,只改 Base URL。

### 2.2 准备环境

- Python 3.10+(建议 3.11 / 3.13)
- 磁盘预留 **2 GB 以上**(InsightFace 模型权重 + 依赖,首次启动会下载)
- 内存 **8 GB 起**;纯 CPU 推理一张大图要 1~3 分钟,建议有 NVIDIA 显卡

### 2.3 安装依赖

```bash
# 1) 建虚拟环境(强烈建议,InsightFace 依赖较重,别污染主项目环境)
cd <你放服务的地方>
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
# source .venv/bin/activate

# 2) 装依赖
pip install -r requirements.txt
```

`requirements.txt` 至少要包含:

```
fastapi
uvicorn[standard]
insightface
onnxruntime          # CPU 版;有 N 卡可换 onnxruntime-gpu
pillow
numpy
python-multipart     # 收 multipart 表单
```

> **insightface 装不上?** 它要编译,Windows 常见问题是缺 MSVC 工具链。
> 装 [Visual Studio Build Tools](https://visualstudio.microsoft.com/downloads/)
> 里勾「使用 C++ 的桌面开发」再重试;或者直接用 `insightface` 的预编译 wheel。

### 2.4 写服务本体

新建 `app.py`,协议按本项目客户端的期望实现(**字段名不能改**,改了就对不上):

```python
# -*- coding: utf-8 -*-
"""本地 InsightFace 换脸服务 —— 与本项目 face_swap.py 协议一致。

    GET  /health  → {"status": "ok", "model": "...", "providers": [...]}
    POST /swap    ← {"source_url": "data:...", "template_url": "data:...",
                    "source_index": 0, "template_index": 0,
                    "swap_all_faces": true, "face_enhance": false,
                    "output_format": "png"}
                 → {"ok": true, "image_base64": "...", "elapsed_ms": 1234,
                    "source_face_count": 1, "template_face_count": 1}
"""
import base64, io, time
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel
from PIL import Image

app = FastAPI(title="InsightFace 换脸服务")
app.add_middleware(
    CORSMiddleware, allow_origins=["*"], allow_methods=["*"], allow_headers=["*"])


class SwapReq(BaseModel):
    source_url: str          # 脸来源图(data URL)
    template_url: str        # 被换脸的目标图(data URL)
    source_index: int = 0
    template_index: int = 0
    swap_all_faces: bool = True
    face_enhance: bool = False
    output_format: str = "png"


@app.get("/health")
def health():
    # 真去探一下 InsightFace 是否加载成功 —— 只返回 ok 等于没探测
    try:
        from insightface.app import FaceAnalysis
        global _app
        if "_app" not in globals():
            _app = FaceAnalysis(name="buffalo_l")
            _app.prepare(ctx_id=0, det_size=(640, 640))   # ctx_id=0 用 CPU
        return {"status": "ok", "model": "buffalo_l",
                "providers": ["insightface-local"]}
    except Exception as e:
        # 探不到就明说,别假装 ok —— 本项目看到 ok 才会认为服务可用
        return {"status": "degraded", "model": "buffalo_l", "error": str(e)[:200]}


@app.post("/swap")
def swap(req: SwapReq):
    from insightface.app import FaceAnalysis
    if "_app" not in globals():
        _app = FaceAnalysis(name="buffalo_l")
        _app.prepare(ctx_id=0, det_size=(640, 640))
    try:
        src = _decode(req.source_url)
        tpl = _decode(req.template_url)
        faces_s = _app.get(src)
        faces_t = _app.get(tpl)
        if not faces_s:
            raise HTTPException(400, "来源图没检测到人脸")
        if not faces_t:
            raise HTTPException(400, "目标图没检测到人脸")
        s = faces_s[req.source_index] if not req.swap_all_faces else faces_s[0]
        t = faces_t[req.template_index]
        from insightface import model_zoo
        model = model_zoo.get_model(
            _app.models["buffalo_l"][-1] if hasattr(_app, "models") else
            "inswapper_128.onnx")
        model.get(img=tpl, target_face=s,
                  target=t, source_face=t)
        buf = io.BytesIO()
        tpl.save(buf, format=(req.output_format or "png").upper())
        return {"ok": True, "image_base64": base64.b64encode(buf.getvalue()).decode(),
                "elapsed_ms": 0, "source_face_count": len(faces_s),
                "template_face_count": len(faces_t)}
    except HTTPException:
        raise
    except Exception as e:
        raise HTTPException(500, f"换脸失败: {e}")


def _decode(data_url: str) -> Image.Image:
    raw = base64.b64decode(data_url.split(",", 1)[-1])
    return Image.open(io.BytesIO(raw)).convert("RGB")
```

> 上面是**最小骨架**,用来把端口和协议对上。要更好的换脸质量就按 inswapper_128
> / GFPGAN 做 face_enhance。

### 2.5 启动

```bash
# 在服务目录下(虚拟环境已激活)
uvicorn app:app --host 127.0.0.1 --port 5678
```

看到这行就起来了:

```
INFO:     Uvicorn running on http://127.0.0.1:5678
```

**首次启动会下载 InsightFace 模型(`buffalo_l` 约 300 MB)**,挂在 `~/.insightface/`。
下载完成前 `/health` 会返回 `degraded`,属正常。

浏览器打开 `http://127.0.0.1:5678/health` 验证,应看到:

```json
{"status":"ok","model":"buffalo_l","providers":["insightface-local"]}
```

### 2.6 开机自启(可选)

**Windows**:用 [NSSM](https://nssm.cc/) 把 `uvicorn app:app --port 5678` 注册为服务。

**macOS / Linux**:写个 systemd unit:

```ini
[Unit]
Description=InsightFace Face Swap Service
After=network.target

[Service]
WorkingDirectory=/path/to/service
ExecStart=/path/to/service/.venv/bin/uvicorn app:app --host 127.0.0.1 --port 5678
Restart=always

[Install]
WantedBy=multi-user.target
```

## 三、在本项目里配置

1. 「设置 → AI 服务 → 换脸 → 添加」
2. 服务商选 **`local-faceswap`**
3. Base URL 填 **`http://127.0.0.1:5678`**
4. API Key 留空(本地服务不校验)
5. 点「测试配置」→ 应显示通过

Base URL 那一栏现在是**可点击链接**,点一下能直接开浏览器确认服务是否活着 ——
比在项目里点测试更快。

## 四、排错

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `服务不可达(http://127.0.0.1:5678)` | 服务没起,或端口不是 5678 | 先浏览器开 `/health`;换端口的话 Base URL 跟着改 |
| `连不上` 但服务明明起着 | 配成了 `remote-faceswap`,Base URL 却填了本地地址 | provider 改回 `remote-faceswap`,或把 Base URL 改成远程地址 |
| `/health` 返回 `degraded` | 模型还没下载完 / 依赖缺失 | 看返回里的 `error` 字段;第一次启动多等一会儿 |
| `来源图没检测到人脸` | 图里没有人脸,或脸太小 | 换正面清晰照;`det_size` 调大到 `(640,640)` 以上 |
| 换脸很慢(1~3 分钟) | 纯 CPU 推理 | 装 `onnxruntime-gpu`,`FaceAnalysis(prepare(ctx_id=0))` 改 `ctx_id=1` |
| 装 `insightface` 编译失败 | 缺 C++ 工具链 | 装 VS Build Tools 勾「使用 C++ 的桌面开发」 |
| 检测到人脸但换出来是乱的 | 用了低质量来源照 | 来源图要正脸、无遮挡、光照均匀 |
